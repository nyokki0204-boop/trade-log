# Trade Log

取引記録に加え、トレード口座の総資産（現金＋保有商品の評価額）を記録できます。

## スマホ保存版（Streamlit不要）

`docs/` にブラウザだけで動くPWAを用意しました。GitHub Pages の **Settings → Pages → Build and deployment → Deploy from a branch → main /docs → Save** で公開します。公開URLは `https://nyokki0204-boop.github.io/trade-log/` です。GitHub Pages の公開設定が有効になるまで、URLは開けません。

iPhoneでは公開URLをSafariで開き、共有メニューから「ホーム画面に追加」→「Webアプリとして開く」をオンにします。**追加したアイコンからアプリを開いてから**記録を入力・移行してください。ホーム画面アプリとSafariでは保存領域が別です。端末内の IndexedDB に取引・資産を保存し、入力時にサーバーへ送信しません。初回表示後はオフラインでも開けます。パスワード、GitHubトークン、Streamlit Secretsは不要です。端末のロックを解除した人はアプリの記録を見られます。

### 旧版のデータを移す

ホーム画面の「引き継ぎ」から、旧版の `trade_log.csv` を選択します。資産履歴を旧版で記録していた場合は、旧版の資産タブから `asset_history.csv` をダウンロードして一緒に選びます。選んだ種類のCSVだけが端末内の既存データと置き換わります。画面に件数が表示されたことを確認して移行してください。公開リポジトリのCSVをアプリが自動取得することはありません。

### 機種変更・バックアップ

古い端末の「引き継ぎ」→「バックアップを書き出す」で取引と資産の `.json` ファイルを安全な場所に保存します。新しい端末でホーム画面にアプリを追加し、そのアイコンから開いて「復元」でファイルを選びます。件数と上書き内容を確認してから復元してください。バックアップは暗号化されていないため、共有・公開しないでください。保存先で実際にファイルが作られたことを確認してください。

端末データは自動同期されません。アプリ削除、Safariの保存領域消去、端末故障などで消える可能性があります。記録を更新したらバックアップを取り、別の場所にも保管してください。旧版のCSVが公開リポジトリに存在する場合、移行してもその公開履歴は自動で削除されません。

ローカルでの確認: `node --test test_web_model.mjs`。`python -m http.server 8000 -d docs` で配信し、`http://localhost:8000/` から動作を確認できます（file:// では利用できません）。

以下は従来のStreamlit版についての説明です。

## iPhone のホーム画面から開く

一度だけ、**公開済みのアプリ本体の URL**（`*.streamlit.app`）を Safari で直接開きます。Streamlit の管理画面の URL や GitHub の URL ではありません。Safari の共有メニューから「ホーム画面に追加」を選び、「Webアプリとして開く」をオンにして追加してください。以後はホーム画面の Trade Log アイコンから直接開けます。アプリを開くたびに Streamlit の管理画面を経由する必要はありません。

まだアプリを公開していない場合は、Streamlit Community Cloud でこのリポジトリの `main` ブランチ・`app.py` をデプロイし、その固定 URL を使ってください。GitHub に変更を反映した後も同じホーム画面のアイコンから開けます。無料ホスティングでは起動に時間がかかる場合があります。これはホーム画面への追加では解消しません。

## 総資産タブの準備

資産額は機密情報です。この公開リポジトリには保存しません。総資産タブを使用するには、資産履歴専用の**非公開** GitHub リポジトリを作り、Streamlit アプリの Secrets に以下を設定してください。`assets_github_token` はその非公開リポジトリの Contents 読み書き権限を持つ fine-grained token にします。トークンとパスワードをコードや公開リポジトリへ書き込まないでください。

```toml
github_token = "取引記録用の既存トークン"
github_repo = "nyokki0204-boop/trade-log"
assets_github_repo = "ユーザー名/資産履歴用の非公開リポジトリ"
assets_github_token = "非公開リポジトリ専用のトークン"
assets_access_password = "長くて推測されにくい画面用パスワード"
```

画面用パスワードは、アプリの URL を知る人から資産額を隠すためのものです。共有アプリで使う場合は、アプリ全体にもアクセス制限を設けてください。保存時にリポジトリが非公開であることを確認し、`data/asset_history.csv` に履歴を保存します。設定前は総資産の保存や表示はできません。

最初の記録が比較の基準です。以降は同じ通貨で総資産を入力し、前回からの外部入金をプラス、出金をマイナスとして合算して入力します。内部の売買や口座内の振替は外部入出金に含めません。入出金を除いた増減は `最新総資産 − 最初の総資産 − 累計入出金` で計算します。評価損益、配当、手数料、為替変動も口座総資産に反映されるため、この数値は個別取引の損益合計とは一致しません。

入出金が発生した時刻は記録していないため、入出金を考慮した正確な運用利回り（％）は表示しません。最新記録の金額や入出金は修正できます。過去の入出金が間違っていた場合は履歴をバックアップし、影響する最新記録から取り消して再入力してください。
